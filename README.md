# Source Code – Business Intelligence Project

## Overview

These folders contains the source code used for the implementation of the Business Intelligence (BI) project. The code supports the data processing, analysis, and reporting activities carried out as part of the project.

## Purpose

The files in this folder document the technical implementation of the project, including the scripts and processes used to work with the project datasets and generate analytical results.

## Supporting Files

- **Data:** Excel files and datasets are stored in the `data` folder.
- **Screenshots:** Images showing the implementation and results are stored in the `screenshots` folder.

The source code is provided for review, verification and reference.
